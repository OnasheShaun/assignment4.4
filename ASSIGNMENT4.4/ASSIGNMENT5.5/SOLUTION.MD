# Assignment 5.5 — CSS Fundamentals Mini-Project

Aim: To style the multi-page college club website created in Week 4 using external CSS, a consistent color palette, CSS variables, reusable selectors, responsive layouts, and clean styling.



## 1. Four-to-five-line explanation of design choices



The website uses a consistent blue, teal, and white color palette to create a clean and professional appearance. Arial typography and clear heading sizes improve readability. CSS variables are used to manage colors, spacing, and other reusable design values. Navigation bars, buttons, cards, forms, and tables share common styles across all four pages. Responsive CSS and media queries help the website adapt to mobile devices and smaller screens.
