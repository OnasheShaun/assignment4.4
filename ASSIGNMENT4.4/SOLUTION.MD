# Assignment 4.4 — Metadata & Page Setup

Aim: To update HTML projects with proper metadata, responsive viewport settings, meaningful page titles, a meta description, a favicon, and correct CSS file paths.

## 1. Metadata code

<head>
    <!-- Character encoding -->
    <meta charset="UTF-8">

    <!-- Responsive design for mobile devices -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <!-- Page title -->
    <title>Student Portfolio | Home</title>

    <!-- Page description -->
    <meta
        name="description"
        content="Explore my student portfolio, technical skills, academic projects, and web development learning journey."
    >

    <!-- Favicon -->
    <link rel="icon" type="image/png" href="images/favicon.png">

    <!-- External CSS -->
    <link rel="stylesheet" href="style.css">
</head>
